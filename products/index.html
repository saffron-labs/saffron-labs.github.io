Visual Code

A C++ editor for students learning data structures and OOP. Write code and watch it drawn as you type: nodes, pointers, arrays, classes, objects, the call stack and recursion.

  • Linked lists, stacks, queues, trees, heaps, hash tables and graphs
  • Classes and inheritance: see each object's parts, constructor and destructor order, and which function a virtual call picks
  • Step forward and back through the program one line at a time
  • Plain-English warnings for NULL pointers, lost nodes and endless loops
  • 56 ready examples, from bubble sort to Dijkstra and virtual functions
Open Visual Code → Start with a blank file No sign-up. Works on laptops and phones.

Found a bug?

Visual Code is new and students write code we never thought of. If a drawing, a step or the output looks wrong, tell us. Every report gets read, and fixes go straight to this site.

  1. Open the report form from the appPress Report a bug at the top of Visual Code. It attaches the code in your editor for you.
  2. Say what went wrong in a line or two"After line 14 the new node isn't linked to head" is all we need. What you expected helps too.
  3. Send it from your email, or copy itIt goes to hello@saffronlabs.in. Add your email if you'd like to hear when it's fixed.
